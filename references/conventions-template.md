# 기본 리뷰 기준

저장소에 `CONVENTIONS.md`, `CONTRIBUTING.md`, `AGENTS.md`, 린터 설정이 없을 때만 이 기준을 쓴다. 있으면 저장소의 규칙이 우선한다.

## 코드

- 함수 하나는 한 가지 일만 한다. 길이가 화면 한 장을 넘으면 C2로 분리를 제안한다.
- 이름은 동작이나 의미를 드러낸다. 약어는 프로젝트에서 이미 쓰는 것만 쓴다.
- 오류를 조용히 삼키지 않는다. 처리하지 않을 예외는 위로 전달한다.
- 같은 로직이 3번 이상 반복되면 C2로 공통화를 제안한다.

## 테스트

- 새 로직과 버그 수정에는 테스트가 따라온다.
- 테스트의 기대값은 구현에서 계산하지 않고 독립적으로 정한다.
- 정상 경로 하나만 있는 테스트는 실패 경로와 경계값이 빠진 것으로 본다.

## PR

- 제목과 설명이 변경 의도를 설명한다.
- 한 PR은 한 가지 목적만 가진다. 관련 없는 변경이 섞여 있으면 C2로 분리를 제안한다.
- 비밀 값, 개인정보, 생성된 대용량 파일이 커밋되지 않았다.
